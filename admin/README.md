# 山野咖啡 · 后台管理

React 19 + Vite + TypeScript + Tailwind CSS v4 + shadcn/ui（底层原语为 Base UI，未使用 Radix）+ Recharts + React Router。

## 启动

```bash
# 1. 先启动 API 服务（另开终端）
cd server
npm install
npm run dev          # http://127.0.0.1:3000

# 2. 启动后台
cd admin
npm install
npm run dev          # http://127.0.0.1:5101
```

接口地址默认指向 `http://127.0.0.1:3000`，可通过环境变量覆盖：

```bash
VITE_API_BASE_URL=http://127.0.0.1:3000 npm run dev
```

## 默认账号

后台账号由 server 种子数据创建，用户名为 `admin`（管理员）与 `staff`（店员，绑定望京店）。

密码不在代码中保存：首次启动 server 时通过环境变量 `ADMIN_PASSWORD` / `STAFF_PASSWORD` 指定；未指定则自动生成并打印在 server 启动日志中（仅显示一次）。账号的新增、停用、重置密码在「账号与角色」页面完成。

会员登录演示验证码固定为 `123456`（小程序 / Web 端使用）。

## 构建产物

`npm run build` 后产物位于 `dist/assets/`，js 手动分包（`react-vendor` = react / react-dom / router，`recharts` = 图表库）：

| 文件 | 说明 | 大小 |
|-|-|-|
| `index-*.js` | 业务代码 | 约 183 kB（未压缩合计） |
| `react-vendor-*.js` | React / React DOM / Router | 约 430 kB（未压缩合计） |
| `recharts-*.js` | Recharts 图表库 | 约 353 kB（未压缩合计） |
| `rolldown-runtime-*.js` | 打包运行时 | 约 1 kB（未压缩合计） |

**js 合计约 967 kB（未压缩合计，gzip 后约 294 kB）**；CSS 约 61 kB（未压缩合计，gzip 后约 11 kB）。端口固定 5101（`strictPort`）。

## 角色权限

| 功能 | 管理员 | 店员 |
|-|-|-|
| 数据看板 | 全部门店 | 仅本门店 |
| 订单管理 | 全部门店 | 仅本门店（列表与推进） |
| 商品管理 | 新增 / 编辑 / 上下架 / 售罄 / 规格组 | 售罄（服务端强制仅本门店） |
| 门店管理 | 可编辑、手动休息 / 恢复营业 | 不可见 |
| 会员管理 | 可查看 | 不可见 |
| 优惠券管理 | 可管理（满减 / 折扣、发放总量） | 不可见 |
| 账号与角色 | 可管理 | 不可见 |

菜单、按钮与路由均按角色控制；服务端同样会做角色校验，前端隐藏只是体验优化。

会话失效（接口返回 `code === 10002` 或 HTTP 401）时，客户端统一清理本地会话并把状态置为未登录，由路由守卫跳转登录页。

## 页面

- 登录：账号密码登录，未登录访问受保护页面会跳转登录页
- 数据看板：今日营业额 / 订单量 / 客单价 / 新增会员、近 7 天营业额趋势、热销 Top10、最新订单
- 订单管理：按门店 / 状态 / 日期 / 关键词筛选，订单详情（含“推进状态”按钮），推进订单状态
- 商品管理：商品列表（筛选、分页）、新增与编辑、上下架、按门店售罄（全局 / 单门店）、规格组（杯型 / 温度 / 糖度）
- 门店管理：门店信息与营业时间编辑、手动休息 / 恢复营业（营业状态按北京时间自动计算）
- 会员管理：会员列表（手机号脱敏）、等级与积分、订单与优惠券详情
- 优惠券管理：满减券 / 折扣券模板的创建、编辑（可切换类型）、发放总量调整、停用
- 账号与角色：账号新增、停用、重置密码、角色与门店分配（店员必须绑定门店）
- 活动管理：第二杯半价活动的启用状态、开始/结束时间（北京时间，精确到秒）与适用商品；后台订单明细会显示活动优惠金额
- 404：未知路由展示中文 404 页，可一键返回看板

## 设计说明

- 品牌主题变量集中在 `src/index.css`（深山棕主色、焦糖点缀、抹茶辅助），三个前端共用同一套品牌视觉
- 插画与图标均为自绘 SVG 或 Lucide 图标，不依赖外部图片或 CDN
- 金额在界面统一格式化为 `¥xx.xx`（接口传输为整数“分”）；时间按北京时间展示（接口为 UTC ISO8601）

## 已知问题

- 支付为模拟支付；后台不提供收银台，订单支付在小程序 / Web 端完成
- 暂无操作日志与登录日志页面（服务端仅记录请求日志）
- 数据看板暂不支持自定义日期范围（固定今天与近 7 天）
- 会员详情中的优惠券暂不支持手动核销
- 会话失效（token 被重置 / 过期）时会清理本地会话并跳转登录页，当前页面未提交的筛选条件不会保留
- 店员账号的售罄 / 订单操作被服务端限制在本门店，前端隐藏菜单只是体验优化
