# 错误码登记表（server）

所有 API 出错时返回 `{"code": <非0>, "data": null, "message": "<中文原因>"}`，HTTP 状态码如下表。

| code | HTTP | message | 说明 |
|-|-|-|-|
| 10000 | 400 | 请求参数错误 | 参数缺失或格式不正确 |
| 10001 | 400 | 手机号格式不正确 | 会员登录手机号校验失败 |
| 10002 | 401 | 未登录或登录已过期 | 缺少或无效 token |
| 10003 | 403 | 没有权限执行该操作 | 角色不符（如店员访问管理员接口） |
| 10004 | 404 | 资源不存在 | 通用 404 |
| 10005 | 400 | 验证码错误或已过期 | 短信验证码不为固定演示值 |
| 10006 | 401 | 账号或密码错误 | 后台登录失败 |
| 20001 | 404 | 门店不存在 | 门店 id 无效 |
| 20002 | 400 | 门店休息中，暂无法下单 | 营业时间外下单 |
| 30001 | 404 | 商品不存在 | 商品 id 无效 |
| 30002 | 400 | 商品已下架 | 商品被后台下架 |
| 30003 | 400 | 商品已售罄 | 商品被标记售罄 |
| 40001 | 404 | 优惠券不存在 | 券模板或用户券 id 无效 |
| 40002 | 400 | 优惠券已领取过，快去使用吧 | 重复领取同一券模板 |
| 40003 | 400 | 优惠券已使用 | 券已被核销 |
| 40004 | 400 | 优惠券已过期 | 超过有效期 |
| 40005 | 400 | 订单金额未满足优惠券使用条件 | 未达到满减门槛 |
| 50001 | 404 | 订单不存在 | 订单 id 无效 |
| 50002 | 400 | 当前订单状态不允许该操作 | 非法状态流转 |
| 50003 | 403 | 无权操作该订单 | 非本人订单或店员跨门店操作 |
| 50004 | 400 | 订单中没有有效商品 | 下单商品全部失效 |
| 10999 | 500 | 服务器开小差了，请稍后再试 | 未预期异常 |

> 新增错误码时需同步更新 `src/lib/errors.ts` 与本文件。
