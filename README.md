# 山野咖啡 · 门店点单平台

> 虚构品牌，门店、地址、商品、价格和会员均为示例数据，仅用于 AI 编程实测。

本仓库由 Step 5 Preview（阶跃星辰）通过 Step Code 编程助手完成，需求见 `docs/brief.md`，任务见 `todo/`。

- 提交作者 `step-5-preview`：模型自己的提交
- 提交作者 `host`：主持者的初始化或人工介入

| 目录 | 内容 | 技术栈 |
|-|-|-|
| `server/` | API 服务 | Node.js + TypeScript + Fastify + SQLite |
| `admin/` | 后台管理 | React + shadcn/ui（Base UI）+ Tailwind CSS v4 |
| `web/` | 品牌官网与会员中心 | Vue 3 + Vite |
| `miniapp/` | 点单小程序 | uni-app（编译到微信小程序） |

## 快速启动

四个子项目需分别启动（端口：server 3000 / admin 5101 / web 5102 / miniapp H5 5103）：

```bash
cd server  && npm install && npm run dev   # API 服务（先启动）
cd admin   && npm install && npm run dev   # 后台管理
cd web     && npm install && npm run dev   # 品牌官网
cd miniapp && npm install && npm run dev:h5 # 小程序 H5 调试
```

各子项目的详细启动命令、默认账号与已知问题见各自目录下的 `README.md`。

## 仍存在的已知问题

1. **推送待完成**：v0.30（第二杯半价活动）在本地提交成功，但因本机到 GitHub 的网络中断（`curl 52 Empty reply from server`）多次重试均未推送成功；网络恢复后执行一次 `git push` 即可（含后续提交会一并推上去）。
2. **支付为模拟**：未接入微信支付 / 真实支付渠道；短信验证码为演示固定值 `123456`。
3. **微信开发者工具限制**：请求 `http://127.0.0.1:3000` 需在工具里勾选“不校验合法域名”（开发期）；上线需配置 HTTPS 域名。
4. **本地缓存依赖**：小程序与官网的登录态、购物车存于本地缓存，清除缓存或卸载后重置。
5. **SQLite 单文件**：未做读写分离与分库分表，高并发写入依赖 `busy_timeout` 重试。
6. **后台账号密码**：只能通过环境变量指定或首次启动随机生成，暂无自助修改密码入口（T15 已提供管理员重置他人密码的能力）。
7. **商品图片**：`image` 字段已预留但种子数据未附本地图片，各端使用自绘 SVG 插画占位。
8. **活动模型**：第二杯半价当前为“单活动”配置模型，暂不支持多活动并行；活动优惠按购物车行累计计数（同商品不同规格时，后加入的一行享半价）。
9. **官网以下单浏览为主**：完整点单流程在小程序端，官网会员中心只读订单/积分/优惠券。
10. **admin 构建产物提示**：`npm run build` 会提示 chunk 体积警告（单包 ~450KB），未做代码分割，功能正常。
