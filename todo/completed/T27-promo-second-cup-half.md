# T27 第二杯半价活动

阶段：S4 需求变更
状态：已完成（v0.30，2026-09-26）

## 要做什么
新增“第二杯半价”营销活动，四端联动：

- **server**：新增活动表与适用商品表；提供活动配置接口（管理员）与当前活动查询接口（公开）；计价时同一订单中同一适用商品的第二杯按半价计算，与优惠券叠加时先算活动价再用券；订单记录活动优惠金额，订单详情返回该金额。
- **admin**：新增活动管理页，可配置活动开始时间、结束时间、启用状态与适用商品（管理员权限）；后台订单明细显示活动优惠金额。
- **miniapp**：商品与购物车体现“第二杯半价”标识，确认订单金额明细展示活动优惠，下单金额与服务端一致。
- **web**：菜单页对适用商品展示活动标识与说明。

## 完成标准
- 同一适用商品第 2、4… 杯按半价计入，活动优惠金额在 server / admin / miniapp / web 一致
- 活动价与优惠券叠加时先算活动价再用券（券门槛按活动后金额判断）
- 活动未开始或已结束时不产生优惠；未配置适用商品时不产生优惠
- 后台可改配置并立即生效；已有功能（下单、支付、券、积分）不被破坏
- 相关构建、类型检查、测试全部通过
