# 山野咖啡 · 门店点单平台（四端完整项目）

你要在当前目录从零搭建一个真实可运行的咖啡连锁点单平台，包含四个子项目：

```
server/    API 服务
admin/     后台管理系统
web/       品牌官网 + 会员中心（Web 端）
miniapp/   用户点单小程序（uni-app，编译到微信小程序）
```

我们会分阶段推进，每个阶段我会单独告诉你做哪一部分。请先通读全部需求，再开始当前阶段。

## 全局约定（所有阶段都必须遵守）
1. 所有 API 返回 `{"code": 0, "data": ..., "message": "ok"}`；出错时 `code` 非 0，`message` 为中文原因。错误码登记在 `server/docs/errors.md`。
2. 金额一律用整数“分”存储和传输，只在界面上格式化为 `¥xx.xx`。
3. 时间一律用 UTC ISO8601 字符串存储和传输，界面按北京时间显示。
4. 手机号在列表、日志和非本人接口中脱敏为 `138****1234`。
5. 不依赖任何外部图片或 CDN。商品图、插画和图标用自绘 SVG、CSS 或本地资源实现，需要自己把它做好看。
6. 三个前端共用同一套品牌视觉：主色、字体层级、圆角、间距要统一，并写入各端的主题变量文件。
7. 每个子项目都有 README，写明启动命令、默认账号和已知问题。

## 业务
- **门店**：3 家门店，各有营业时间和营业状态（营业中 / 休息中）。
- **商品**：分类（咖啡、茶饮、轻食、周边）；至少 24 个商品；规格含杯型（中 / 大，大杯加 3 元）、温度（冰 / 热）、糖度（无 / 少 / 标准）；可上下架、可售罄。
- **会员**：手机号 + 验证码登录（验证码固定为 `123456`，模拟即可）；每消费 1 元积 1 分；会员等级：银卡（0 分）、金卡（500 分）、黑卡（2000 分）。
- **优惠券**：满减券、折扣券，有有效期；下单时自动推荐最优券，也可手动选择。
- **订单**：自提或堂食；状态为待支付 → 已支付（模拟支付）→ 制作中 → 待取餐 → 已完成，任意支付前状态可取消；每单生成 4 位取餐码。
- **后台角色**：管理员（全部权限）、店员（只能处理本门店订单、修改售罄状态）。

## 各子项目要求
### server（API）
Node.js 24 + TypeScript + Fastify + SQLite。启动时自动建表并写入种子数据。提供 OpenAPI 文档页。

### admin（后台管理）
React 19 + Vite + TypeScript + shadcn/ui + Tailwind CSS v4。shadcn 组件的底层原语必须使用 Base UI（`@base-ui/react`，用 `npx shadcn@latest init` 时选择 Base UI），不使用 Radix；图表使用 shadcn Chart（Recharts）；路由使用 React Router。页面：登录、数据看板（今日营业额、订单量、近 7 天趋势、热销 Top10）、商品管理（含规格、上下架、售罄）、订单管理（按门店 / 状态 / 时间筛选，推进状态）、门店管理、会员与优惠券管理、账号与角色。店员登录后只看到有权限的菜单和按钮。

### web（品牌官网 + 会员中心）
Vue 3 + Vite + TypeScript。页面：首页（品牌主视觉、当季推荐、门店入口）、菜单（按分类浏览）、门店（列表、营业状态）、品牌故事、会员中心（手机号登录后查看订单、积分、等级、优惠券）。适配手机、平板、桌面，这一端最能体现品牌审美。

### miniapp（点单小程序）
uni-app（Vue 3 + Vite），编译目标为微信小程序（mp-weixin），接口基地址可配置，默认 `http://127.0.0.1:3000`。页面：
- 首页：门店选择、轮播、推荐；
- 点单：左侧分类、右侧商品，规格弹窗，底部购物车浮层；
- 确认订单：自提 / 堂食、优惠券选择、金额明细；
- 订单详情：取餐码、进度条；
- 我的：会员卡、积分、优惠券、订单列表。
